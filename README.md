# Asymmetric_Encryption_Lab


🔐 Lab 3.14: Asymmetric Encryption (Zybooks)
This lab introduces the principles of asymmetric encryption, a cryptographic method that uses a pair of keys: a public key for encryption and a private key for decryption. Asymmetric encryption is widely used in secure communications, digital signatures, and certificate-based authentication.

🧠 Learning Objectives

--Understand how public and private key pairs work

--Encrypt messages using a public key

--Decrypt messages using the corresponding private key

--Generate and manage RSA key pairs

--Explore real-world use cases like SSL/TLS and PGP

🧪 Tools and Concepts Used

--OpenSSL (or built-in Linux crypto tools)

--RSA algorithm

--Public key encryption

--Private key decryption

--Key generation (openssl genpkey, openssl rsa)

--File encryption/decryption with key pairs

✅ Tasks Completed

1) Generated RSA public/private key pairs

2) Encrypted a plaintext file using the public key

3) Decrypted the ciphertext using the private key

Verified the integrity and confidentiality of the transmitted message

Reviewed how asymmetric encryption is used in digital certificates
